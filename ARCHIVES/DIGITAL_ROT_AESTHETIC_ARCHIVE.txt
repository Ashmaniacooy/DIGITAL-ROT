# NOTES ON STRUCTURE

AESTHETIC ARCHIVE intentionally contains several different kinds of
creative material because DIGITAL ROT relies on combinations between
theme, atmosphere, digital culture, horror language and material decay.

However, some entries overlap conceptually with ART STYLE / RENDERING
ARCHIVE or with a possible future MEDIA / SOURCE ARCHIVE.

Such entries are retained for now rather than deleted.

Examples:

Glitch Art / Datamosh / Pixel Sorting
→ can function as aesthetic direction or visual treatment.

VHS / DVD / MiniDV / Webcam
→ primarily media/source language, but remain useful as aesthetic
references for DIGITAL ROT.

PS1 / PS2 / Low-Poly
→ can describe an era/world aesthetic while also interacting with
rendering style.

Photocopy / Fax / Scanline / CRT
→ can function as material/media aesthetics as well as rendering
treatments.

These distinctions should be finalized only after ART STYLE and
LAYOUT archives are complete.

# CORE DIGITAL ROT AXES

The archive can broadly be understood through several major axes:

DIGITAL
→ Glitch, data corruption, software failure, computer culture

INTERNET
→ Old Web, Y2K, lost websites, dead internet, online memory

ANALOG
→ VHS, broadcasts, surveillance, archival media, signal failure

DREAM
→ Dreamcore, liminal space, false memory, uncanny reality

DARK
→ Gothic, occult, dark fantasy, religious horror

DECAY
→ Rot, mold, rust, organic corruption, ruins

CUTE × DARK
→ Kawaii, dolls, toys, mascots, corrupted childhood imagery

RETRO
→ Y2K, PS1/PS2, retro computers, vaporwave, cassette futurism

CULTURE / PLACE
→ Postsovietcore, Chernobylcore, Warcore, Creepypasta, internet
meme culture

The purpose of these axes is not to restrict combinations, but to make
the archive easier to navigate and combine later.
