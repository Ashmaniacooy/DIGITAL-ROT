=== UNKNOWN — FIXED IDENTITY SYSTEM ===

UNKNOWN does NOT mean visually undefined.
UNKNOWN = character/OC whose name, franchise, or source is unknown or unconfirmed, but whose visual identity is fixed by the archive.

RULES FOR GENERATION
1. IDENTITY LOCK is immutable. Never redesign, randomize, simplify, replace, or "improve" these traits.
2. SCENE DNA describes the source/reference context. It may be preserved or intentionally replaced when an aesthetic requires a new setting.
3. STYLE VARIABLES are the layer that aesthetics are allowed to modify: rendering treatment, lighting, atmosphere, background treatment, camera/media appearance, color grading, glitch/decay intensity, and presentation.
4. If an aesthetic conflicts with IDENTITY LOCK, preserve the character identity and apply the aesthetic to presentation rather than changing the character.
5. The original visual description below is retained so every UNKNOWN can be reconstructed from the archive without inventing missing details.
6. Do not infer a canonical name, franchise, personality, anatomy, clothing, or accessories that are not supported by the archive.

FORMAT
- IDENTITY LOCK = what must remain recognizable.
- SCENE DNA = source-image pose/background/composition/context; not automatically permanent.
- STYLE VARIABLES = what the aesthetic layer may change.
- ORIGINAL ARCHIVE DESCRIPTION = exact source-derived description retained for reconstruction.
